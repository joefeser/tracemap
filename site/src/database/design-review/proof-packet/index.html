Public claim boundary

The packet supports design review, not a database conclusion.

  • It does not inspect a live database or catalog, execute SQL, queries, migrations, functions, jobs, or application code, or prove that a migration was applied.
  • It does not prove runtime provider or connection selection, generated SQL, search-path behavior, branch feasibility, runtime reachability, traffic, authorization, deployment, or user exercise.
  • It does not establish current or production schema, data correctness, compatibility, effective permissions, rollback, operational success, release approval, DBA approval, or that anything is safe to run.
  • It contains no raw SQL, source snippets or snippet hashes, credentials, connection strings, scheduled command bodies, local paths, private infrastructure identities, raw command output, raw SQLite, or arbitrary fact properties.
  • The core scanner and reducer use no LLM calls, embeddings, vector databases, or prompt-based classification.
