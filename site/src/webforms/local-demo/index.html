Web Forms · reproducible local demo

Replay the public corpus, then inspect the right artifact.

The one-command local workflow builds checked-in synthetic Web Forms projects, scans attached and separate provider layouts, retains bounded reports, and refuses unsupported or incomplete acceptance states. It does not need customer code or a database.

Public claim level: demo. The validation receipt below is bound to one exact public synthetic tree and durable Windows result. Workflow orientation without a matching projected artifact remains concept. Raw indexes, facts, logs, test receipts, binaries, source, and machine-local paths remain hidden.

Choose the replay

Local static replay and Windows publication are separate gates.

Default local replayUse PowerShell 7, the documented .NET toolchain, and a fresh output root. pwsh -File scripts/wlocal.ps1 -OutputRoot <fresh-output-root> exercises checked-in public fixtures only.
Authentic publication-RequireWindowsPublish additionally requires mapped and mapless ASP.NET publication on Windows. A non-Windows refusal or skipped Windows theory is not a pass.
PrerequisitesFollow the validation guide, the native workflow, and the public corpus map.
Execution boundaryThe workflow builds and analyzes fixture artifacts. It does not launch a Web Forms site, execute fixture database methods, run SQL, or observe a user request.

Non-claims and remaining gaps

The demo stops at deterministic static evidence.

  • No runtime page, fixture method, database command, branch, provider dispatch, parameter value, or returned-row observation.
  • No customer compatibility, private application coverage, migration parity, complete cross-service tracing, physical drive-I/O measurement, release approval, or safety-to-run claim.
  • Candidate bridges, unresolved values, Tier4Unknown gaps, result caps, and partial/reduced coverage remain visible; missing evidence is not runtime absence.
  • PR #803 diagnostics and scheduling repairs are not ancestors of this page's exact main boundary and are not described as shipped.
  • No raw SQLite, facts.ndjson, analyzer log, TRX, source snippet, raw SQL, command body, configuration, credential, connection material, private identity, local path, customer artifact, or unpublished validation output is public.
  • No LLM call, embedding, vector database, or prompt-based classification is part of this evidence.
