Public claim boundary

A recorded build result is not a release conclusion.

  • The packet does not authenticate or attest the binary log, or prove it was produced from the declared commit.
  • A recorded succeeded result does not prove tests passed, the repository was clean, deployment occurred, runtime behavior was correct, or a release is approved or safe.
  • Project and graph evidence does not prove runtime reachability. Missing diagnostics do not prove that defects are absent.
  • The result is one synthetic checked-in sample, not a completeness, compatibility, or performance benchmark.
  • TraceMap core scanning and reduction use no LLM calls, MCP analysis, embeddings, vector databases, or prompt-based classification.
