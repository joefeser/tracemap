# Temporary report comparison

Run `scripts/wcompare.ps1` from PowerShell 7. It pins baseline
`e8121dc1c147923c39adcc1cb3cdbff5fd349d7e` and merged PR #796 at
`f7891d980c2fd8080b70c14d0ea07a834598d35a`; it does not compare a moving dev head.
Choose the previously verified working proof when multiple complete high-work
proofs are listed. `-ProofRoot` and `-OutputRoot` are optional explicit overrides;
an existing output root is rejected. `-NoOpen` disables opening the landing page.

The fresh comparison root contains `index.html`, before/after documents and
logs, two detached code worktrees, and `comparison.receipt.local.json`. The
receipt inventories the saved inputs, exact code pins, handoff hashes, generator
SHA-256 and bounded-input SHA-256. Keep that root and the proof until reviewed.
No automatic cleanup or branch deletion is implemented.

Rule `diagnostic.webforms.report-comparison.v1` compares retained compiled paths
by exact method names, locations, edge kinds, rule IDs, tiers, classifications,
terminal kinds, fact support, source identity, admitted DLL provenance, existing
coverage/gap fields, gap count and truncation. Path order/IDs, labels, HTML formatting
and newly retained gap-detail fields may differ without failing this projection
comparison. An empty path set cannot pass. A difference retains the documents
and receipt but exits with an error. Saved input hashes must remain unchanged.

This is local-only selected-proof reporting parity, not a fresh extraction,
all-pages regression test, normal corpus/docs-export parity, source-line identity,
runtime SQL claim, or proof that every application-workbench field matches.
Existing producers add fresh graph reports/packets beneath the proof root;
inventoried scans/indexes are never regenerated by this helper. Baseline reporting
is explicitly recomputed before its view; merged reporting uses `-RecheckApi`.

Public orchestration guard: `pwsh -NoProfile -File scripts/tests/Test-WCompare.ps1`.
It uses synthetic inputs and mock version checkouts. It does not establish private
Windows acceptance, actual graph-traversal parity, or CI determinism.
