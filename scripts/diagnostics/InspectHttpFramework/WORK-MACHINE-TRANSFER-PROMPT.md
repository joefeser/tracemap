# Work-machine boundary — no contribution or transfer

This file replaces the earlier transfer instructions. Those instructions were
incorrect: the work machine cannot contribute to open source, including patches.

Do not create, export, request, or transfer work-machine code, patches, commits,
application artifacts, or private evidence for this public repository. Do not
retry pushes, change credentials, or treat sanitization as publication approval.

Public implementation and synthetic fixtures must be developed independently on
the authorized machine using public framework references. No work-machine patch
is required or accepted by this workflow.

The work machine may be used only for separately authorized private validation.
Keep its results local. Any feedback requires applicable workplace approval;
absence of such approval is not a blocker for public synthetic development.
