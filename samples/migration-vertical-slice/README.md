# Static migration vertical slice

Public synthetic projectless VB Web Site. Never execute its methods or SQL.

Two source boundaries (page button and user-control button) call an explicitly
typed backend. Its wrapper calls a direct SQL method and an outbound HTTP method.
The SQL method combines nested Try, relative SqlClient names, String.Empty,
concatenation, five parameter additions, complex values and transaction assignment.
An unconnected SQL method must remain in the inventory.

Acceptance: three operation evidence groups, two with ordered candidate paths,
five parameters grouped under the SQL call, both markup boundaries visible,
unknown execution/contract semantics preserved. Removing call or handler evidence
must break paths without deleting operations. Input fact order must not affect
the report. No URL or runtime reachability is inferred from a handler name.

This source slice complements, rather than replaces, SqlWrapperRouteTests and
BackendExtractionSampleTests for compiled caller/wrapper evidence. Separate scans
or tiers are not spliced into one confirmed path.
