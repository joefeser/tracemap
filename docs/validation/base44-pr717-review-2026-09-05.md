## Findings and corrections

Four P2 correctness findings were reproduced and corrected. No P1 finding was
identified in this review.

1. **Conditional spreads lost branch presence.** A payload such as
   `flag ? { ...defaults } : {}` emitted `defaults` fields as spread-derived
   without preserving their conditional presence. Nested spreads now propagate
   the enclosing branch condition.
2. **Reference escapes silently retained complete shapes.** Mutating an alias,
   passing a payload to a helper, or invoking an array mutator could change the
   payload while its evidence remained complete. These bounded reference uses
   now produce typed gaps and Tier4Unknown evidence; post-capture method/helper
   uses also invalidate alias completeness. This is conservative evidence,
   not a claim to evaluate helpers or reconstruct a general alias graph.
3. **Same-line calls collided.** Two identical entity calls on one source line
   produced the same operation linkage and collapsed during fact deduplication.
   Source character offsets now distinguish operation IDs and linked shape
   facts without retaining raw source.
4. **Shadowed bindings borrowed unrelated fields.** Parameters, destructured
   bindings, and later local declarations could fall through to an outer
   initializer. Lexical binding selection now precedes source-order checks;
   unsupported shadowing bindings remain unresolved. Catch bindings are scoped
   to the catch clause so they cannot contaminate later sibling code.

The TypeScript suite adds 18 regression/control cases, including artifact-level
operation linkage and controls for later mutations, nested unexecuted helpers,
unrelated shadowed objects, and Object.assign source copies. The first eight
regressions failed before the corresponding fixes. Additional shadowing cases
were also run before their fix and reproduced the incorrect evidence.

The rule catalog and consumer contract document the new gaps and limits.
Operation IDs change with this extractor revision; regenerate both comparison
snapshots with the same extractor version.
