## Corrected findings

- **P1 — Unknown provenance propagated downstream.** Candidate discovery
  retained an SDK seed even when another upstream call supplied an unknown
  value. Downstream helpers treated that seed as proof. A bounded invalidation
  pass now removes all dependents of an unproven parameter, including cycles.
- **P1 — Several bindings acquired unrelated SDK authority.** Factory calls
  consulted file-wide names without checking lexical shadows; export aliases
  could come from mutable or same-named nested declarations; destructuring and
  named function/class expressions could inherit an outer client. Factories,
  aliases, and exports now require the actual immutable lexical binding, with
  unsupported destructuring left unresolved.
- **P2 — Rest/spread syntax changed argument identity.** A rest parameter was
  treated as a client rather than an array, and a preceding spread could shift
  the actual argument position. Both now prevent positional propagation.
- **P2 — Loop writes preserved parameter authority.** Assignment through
  for-in/for-of was missed by the binding-write check. Those writes now
  invalidate the parameter before operation emission.
- **P2 — Exported immutable helper expressions disappeared.** The immutability
  check compared the declaration position to the start of the module, making
  named/default exported arrow helpers impossible to resolve. Import resolution
  now uses the module end as its declaration boundary.
- **P2 — Function invocations omitted injected provenance.** Newly reached
  function-invocation facts now carry the same client-binding kind as their SDK
  primitive fact. Payload/query facts retain their operation-ID linkage.

The dedicated review suite adds 27 regression/control cases. The first 17
regressions all failed on the reviewed head. Subsequent targeted checks also
reproduced loop-write and function-provenance failures before those fixes.
A final regression reproduced dotted-literal property paths colliding with
multi-segment paths; candidates now preserve segment boundaries with JSON array
identities. Positive controls preserve seeded recursion, direct factories, immutable factory
aliases, namespace aliases, and a spread after the client argument.
