# End-to-end acceptance: outcome contract

Authored before implementation of the integration route. This supersedes the
earlier bounded-slice completion criterion, not its compatibility denominators.
No private identifiers, source or data are inputs to this corpus.

## Required pipeline

Compile separate C#/VB caller and wrapper assemblies; scan with the actual CLI;
admit independently authored public SQL result declarations and exact execution
bindings; compare via a distinct compiled-lineage route; emit linked JSON and
human-readable results with generator/input hashes. Never relabel Tier3 encoded
IL evidence as Tier1 source evidence or reuse source-reader bindings.

The corpus uses property-held state, two independent procedure executions and
two named Merge destinations. An auxiliary application table supplies a guarded
overlay through an inspected helper. Both raw and typed-projection consumers
must retain their distinct read sites. The same pipeline must represent reload,
Clear/re-Merge and partial-failure alternatives, not claim atomicity.

## Independent expected matrix (each language)

| Scenario | Schema comparison | Value origin / required evidence |
| --- | --- | --- |
| First-table Name | match against first procedure | first execution, first destination |
| Second-table Count | match against second procedure | second execution, second destination |
| Typed projection Name | match against first procedure | same column, distinct projection read |
| Overlay Score with true guard | match against first schema | application auxiliary column, not SQL value |
| Overlay Score with false guard | match against first schema | first SQL execution value |
| Overlay Score with unknown guard | match against first schema | guarded union of SQL and application origins |
| Missing column in complete schema | mismatch | never fabricated by row assignment |
| Incomplete SQL schema | unknown | no absence claim |
| Clear then re-Merge | match | new execution value, retained destination/schema identity |
| Reload | match | fresh destination and execution, not prior state |
| Failure before second Merge | partial | first destination may be populated; second is empty |
| Failure during overlay | partial | guarded per-row alternatives, not whole-table overwrite |
| Failure during projection | partial | typed list may be partially populated |
| Unknown helper escape | unknown | no preserved-value claim |
| Stale binary/binding or substituted execution | rejected | no comparison output admitted |

SQL declaration identity and column spelling are authored independently of
extracted hashes. Bindings must match repo/revision, body/binary/site context,
execution and evidence digest. Cross-execution and cross-table substitution are
negative controls. Derived values and row writes do not establish SQL types,
nullability, row existence, business correctness or runtime success.

## Completion gate

All successful rows above must yield linked evidence through scan AND comparison.
Labeling the entire representative flow unsupported is a failing acceptance
result. Unknown guard values retain alternatives rather than force a chosen
branch. Unsupported effects may remain unknown only in the explicit negative
controls. Preserve original 20-root and 26-root smoke denominators independently.
Run frozen full Debug -warnaserror, relevant retained smokes, deterministic replay,
provenance tampering controls and C#/VB parity before publication. No PR or private
machine retry until this gate passes. Runtime/private acceptance remains separate.
