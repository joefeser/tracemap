# Access Screen-to-Data Static Flow Review Prompts

## Evidence review

Verify that every edge is backed by one exact Access fact and that paths only
union cited evidence. Identify any adjacency or name match that manufactures a
runtime conclusion.

## Boundary review

Verify there is no Access/COM/database/source acquisition, execution, row read,
or customer-data path and no raw identity, SQL, VBA, expression, macro body,
connection, or local path in output.

## Determinism review

Reverse input fact order and inspect stable roots, edges, paths, cycles, gaps,
tiers, bounds, JSON, and Markdown.

## Non-claim review

Verify roots are candidates, event/navigation rows are static candidates,
missing evidence is a gap, and the report does not claim runtime reachability,
execution, user behavior, correctness, completeness, or approval.
